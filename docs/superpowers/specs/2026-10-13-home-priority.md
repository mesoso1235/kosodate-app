# ホーム画面の優先順位 設計メモ

- 作成日: 2026-10-13
- きっかけ: 実際に使ってみて「何から手をつければいいか分からない」「全部が同じ重さで並んでいる」
- 決め方: 利用者（夫婦）への質問で1つずつ決めた

## 考え方

調べたポータルサイトの失敗例・改善例から、次の4つを基準にした。

| 考え方 | 出どころ | この画面でどう使うか |
|---|---|---|
| よく使われる少しのことを前に出す | Gerry McGovern「Top Tasks」 | 手続きは最大3件まで |
| 足すより減らす | GOV.UK Design Principles「Do less」 | 中身のない欄・空の欄は出さない |
| 運営側の都合で載っている情報を外す | 業務ポータルの失敗例 | 職員募集・契約結果・終了済みの告知を隠す |
| 全員に同じ画面を出さない／生活の段階で並べる | 自治体の子育てサイト改修例（福岡市・宮崎市など） | 予定日・誕生日から「今の時期」の手続きを出す |

## ホームの並び（上から）

1. **あいさつ＋日数を1行**: 「夜遅くまでおつかれさま」の下に「予定日まで あと100日（1/21）」。大きな数字は使わない
2. **いまやること**（旧「今週やること」）
   - 未完了で、期限まで 0〜30日のもの、または期限を過ぎて 1〜7日のもの
   - 期限の近い順（期限切れが先頭）、最大3件
   - 期限の書き方: 「10/30(金)まで」。残り7日以内は「10/30(金)まで・あと3日」と強める。当日は「今日まで」。過ぎたものは「期限を過ぎました」と添え、「済んでいたらチェックを」と案内する
   - 0件のときは「いま急ぐ手続きはありません。次は「○○」（11/5(木)まで）。」を1行だけ
3. **手が空いたら**: 期限がなく、priority が high で、開始日が来ている未完了のものを1件。開始日の新しい順（早い順だと、妊娠初期の済んでいそうな手続きが出てしまうため）
4. **申し込めるお知らせ**: 最大2件。なければ欄ごと出さない
   - 区などのお知らせ: タイトルに「申込」「申し込み」「予約」「受付」「参加者募集」を含み（「募集」だけだと寄附・事業者の募集まで拾うので使わない）、除外語を含まず、掲載から14日以内
   - LINEで転送したもの: 受け取りから7日以内（絞り込みはしない）
   - LINE転送を先に、それぞれ新しい順
5. **気になるイベント**: ☆を付けたこれからのイベントがあるときだけ出す。空の欄・説明文は出さない

## 『お知らせ』タブ

タイトルの言葉で、はっきり関係ないと分かるものだけ隠す。迷うものは表示する。

除外語: 「終了しました」「募集は終了」「受付は終了」「中止」「区職員」「プロポーザル」「入札」「契約」「二十歳」「中高生」

「職員」だけにすると「区の職員等によるシッティング現場立ち会い」（ベビーシッター支援）まで隠れるので、「区職員」にしている。

## やらないこと

- 『やること』『さがす』『設定』タブは今回変えない（ホームを数日使ってから順に見直す）
- 手続きデータ（期限・URLなど）は変えない

3. `assets/util.js` に、お知らせの除外判定 `isIrrelevantNews` と申込み判定 `isApplyNews` を足す（テスト先行）
4. `assets/views/home.js` を上の並びに書き換え、`assets/style.css` を合わせる
5. `assets/views/news.js` で除外判定を使う
6. `sw.js` の VERSION を上げる
7. 前後のスクリーンショットで確認する
